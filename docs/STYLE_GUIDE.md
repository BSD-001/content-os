# MVP 卡通设计规范

本规范采用用户最新要求：各篇更换卡通构图，同一篇各页统一。替代最早“固定一个模板”的限制。

| 顺序 | 风格 | 构图 |
|---|---|---|
| 1 | 奶油手帐 | 暖色纸卡、圆角标题、胶带与读书人物 |
| 2 | 清爽漫画分镜 | 蓝色网点、粗线标题、对白框与爆炸贴 |
| 3 | 彩色贴纸拼贴 | 绿色方格、椭圆标题、纸片、胶带与贴纸 |

三套循环，新稿保存风格编号与配色变体；改字或重新出图保留本篇选择，避免同一篇突然换风格。三套不同构图均已实际本地渲染；它们不是无限生成的新设计，后续是否扩展根据使用反馈决定。

每页 1080×1440；背景由已有 SVG 和免费插画生成，中文使用本机 Microsoft YaHei 字体。封面与正文标题均衡换行，正文自动按空间缩字号，最低 32px；标题最低 40px。超过安全区域会要求缩短或拆页，不裁切。卡片 1–9 页。

文字在 Content OS 编辑。PNG 导出不等于可画可编辑设计，MVP 不再调用可画。保存文字清空旧图片，重新生成后才能下载整篇。

插画：Open Doodles / Pablo Stanley，CC0；已下载源文件、来源、许可和校验值保存在 assets/cartoon。复用此前核对资源，本轮无需再安装设计工具。当地图片采用此设计规范不代表点击率得到验证。
